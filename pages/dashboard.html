Meeplewood

A board game exploration tool in the making!

Building something useful, being creative, learning new things and make board game data fun to explore.

In other words: 'Because I can'-project ;)

Meeplewood is designed around several board game data sources, mainly logged plays from BGStats and information (like Geek Preview Lists and collection data) exports from BoardGameGeek.

The goal is to bring these data sources together in one place and turn them into useful insights and playful decision support for board game enthusiasts.

Meeplewood is a personal "because I can" project. Not sure when (or if) it will be completed.

Currently working (basic version):

  • * Reviewing GeekPreview Lists (mainly for Spiel, but can be used for all preview lists available on BGG)
  • * Adding preview information locally
