The project

Make board game data fun to explore

Meeplewood brings together logged plays from BGStats, collection data, and Geek Preview lists from BoardGameGeek.

The goal is to turn those sources into useful insights and playful decision support for board game enthusiasts.

  • Explore a collection as an interactive game forest.
