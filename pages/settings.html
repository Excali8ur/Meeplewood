Data Storage

Meeplewood does not have a server or cloud storage. Instead, information is saved in your browser's storage (username and where the data is stored). If you clear your browser data or use a different device, your data will not be available.

Use the settings below to define your username (BGG name is preffered) and where Meeplewood can find the correct files.

No data files yet? Create empty files with the desired names (e.g., 'GeekPreview-data.json' and 'collection-data.json') and use the 'Browse' buttons to select them. Or if you want to update the data, see 'Manage Data Files'-section below.

If you just want to try out the application, without creating your own data files, you can use the example files. In that case, use the example files provided and don't change the paths!.

Where to find your BGG collection export?

Go to your BGG collection, apply any filters you want, then use "Export" to download the CSV file.
No need to change anything in the file, just import it here. Games are merged with any existing collection data in Meeplewood, matched by BGG ID.

Path to your Meeplewood Geek Preview file, used to display the latest game previews. Use the 'Browse' button to select your local file (shows as "local:filename.json")

⚠️ Starting with a new preview file will clear any loaded data and allow you to start importing from scratch. This doesn't delete existing files on your device, it just clears the current session.

Where to find the BGG GeekPreview Lists?

See all GeekPreview Lists on BGG, select the convention you want to add and choose "export" to download the CSV file.
No need to change anything in the file, just import it here and add metadata when prompted. The games will be merged with any existing data you have in Meeplewood.
