🚀 Getting Started

Just want to try MeepleWood?

Start with the included example data. You can explore the application without creating or importing any files.

You can switch to your own data at any time.

Ready to use your own data?

Create your data files, select them below, and then use Manage Data Files to import or update your data.

Set Up My Own Data ↓

📁 Your Data

Tell MeepleWood which files to use for your personal data.

Your BGG username is recommended. It is used as the default user when importing GeekPreview lists.

The JSON file containing your board game collection and logged plays.

Setting up your own data for the first time?
  1. Create the required JSON files on your device.
  2. Select each file using Browse….
  3. Save your settings.
  4. Go to Manage Data Files to import your data.
Need to add or update your data?

Import new GeekPreview lists, update your collection, import play history, or export your data.

📥 Manage Data Files

Use these tools to add or update your MeepleWood data.

GeekPreview Lists

Import a GeekPreview list from BoardGameGeek. MeepleWood will add the games to your existing data.

Export a GeekPreview list as CSV from BoardGameGeek Previews . You can import the CSV here without editing it first.

BGStats

Import your board game collection and play history from a BGStats export file.

BoardGameGeek Collection

Update your board game collection using a BGG collection export.

Export your collection from BoardGameGeek Collection . Apply any filters you want and choose Export. You don't need to edit the CSV before importing it.

BoardGameGeek

Import your collection directly from BoardGameGeek. Your BGG username is required.

Backup

Save a copy of all your MeepleWood data.

Recommended as a backup before making major changes.
